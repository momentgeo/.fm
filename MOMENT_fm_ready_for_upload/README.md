# MOMENT.fm — пакет сайта и Gemini API

## Что уже соединено в проекте

- Главная страница `index.html` обращается к серверному маршруту `/api/gemini`.
- `api/gemini.js` выполняет запрос к Gemini; секретный ключ остаётся на сервере и не попадает в HTML.
- Работают три AI-сценария интерфейса: подводки четырёх ведущих, редактура уже имеющихся новостных карточек и подготовка поисковой фразы для Clip Finder.
- Добавлены проверки входных и выходных данных, ограничение размера запроса, проверка источника браузерного запроса, базовый лимит частоты запросов и обработка ошибок/тайм-аута.
- Повторное нажатие AI-кнопки блокируется, пока предыдущий запрос не завершён.

## Публикация на Vercel

1. Распакуй архив в отдельную папку и загрузи содержимое в новый GitHub-репозиторий. В корне должны лежать `index.html`, `package.json`, `vercel.json`, `.gitignore`, `.env.example` и папка `api`.
2. Импортируй именно этот репозиторий в Vercel. Для статического HTML отдельная сборка не нужна: Framework Preset можно оставить `Other`, Build Command и Output Directory не задавать.
3. В Vercel → Project → Settings → Environment Variables добавь `GEMINI_API_KEY` со своим новым ключом Google AI Studio. Не помещай ключ в `index.html`, GitHub или сообщения.
4. Добавь `APP_ORIGIN` со значением полного адреса опубликованного сайта, например `https://имя-проекта.vercel.app` (без завершающего `/`). Это ограничивает браузерные запросы этим сайтом.
5. При необходимости можно задать `GEMINI_MODEL`; по умолчанию используется `gemini-3.8-flash`.
6. Нажми Redeploy и проверь три AI-кнопки в разделе «Вещание → Gemini AI».

## Важно про GitHub Pages

GitHub Pages не запускает серверный файл `api/gemini.js`. Поэтому эта сборка рассчитана на публикацию на Vercel, где страница и API находятся на одном домене. Если позже понадобится GitHub Pages, фронтенд и API придётся разнести по разным адресам и отдельно настроить адрес API и CORS.

## Что пока НЕ является настоящим эфиром

Это всё ещё прототип интерфейса телеканала. Gemini здесь генерирует только текстовые подводки, редактирует уже загруженные карточки и предлагает поисковую фразу. Он не создаёт голос ведущих, не ищет и не скачивает музыкальные клипы, не проверяет актуальность новостей и не запускает реальный круглосуточный видеопоток. AutoDJ, FFmpeg/OBS/HLS и часть медиа-контролов пока остаются демонстрационными/локальными элементами интерфейса. Для настоящего 24/7-эфира отдельно потребуются медиатека с разрешёнными материалами, сервер автоматизации и потоковая инфраструктура.

## Безопасность и расходы

- Ранее опубликованный API-ключ нужно отозвать и заменить новым. Старый ключ не использовать.
- Ключ добавляется только в Environment Variables на сервере. Файл `.env` не загружать в GitHub.
- В API включён простой лимит запросов в памяти экземпляра функции. Это базовая защита для тестирования, а не полноценная система защиты от злоупотреблений: для публичного запуска потребуются постоянное хранилище лимитов и авторизация административных AI-действий.
- У Gemini могут быть квоты и платные тарифы. Перед включением оплаты или добавлением платёжных данных проверь условия и расходы вместе со взрослым владельцем аккаунта.
